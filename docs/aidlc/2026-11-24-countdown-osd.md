# Investigate a capture countdown OSD

Status: Draft

## Inception

Evaluate whether a capture countdown can stay visible to the user and reliably stay out of captured pixels. Use the [capture design](../capture.md) to identify the supported capture paths and their timing.

### Acceptance criteria

- Document available mechanisms and limitations for labwc, Sway, and Hyprland.
- For each supported capture path, record whether the countdown can stay visible without appearing in the resulting image. Use live compositor evidence for any proposed mechanism.
